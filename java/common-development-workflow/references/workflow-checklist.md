# 工作流程检查清单

## 完整工作流程检查清单

在执行任何代码修改任务时，请使用此检查清单确保完整遵循工作流程。

### 阶段 1：分析阶段

- [ ] **步骤 1：生成分析文档**
  - [ ] 明确修改目标
  - [ ] 列出涉及的文件
  - [ ] 分析当前代码结构
  - [ ] 说明需要修改的内容
  - [ ] 分析影响范围
  - [ ] 列出依赖关系
  - [ ] 制定测试计划

- [ ] **等待用户确认**
  - [ ] 分析文档已提交给用户
  - [ ] 等待用户确认后才能继续

### 阶段 2：实施阶段

- [ ] **步骤 2：生成实施文档**
  - [ ] 制定详细的实施步骤
  - [ ] 列出代码修改清单
  - [ ] 说明代码规范要求
  - [ ] 制定优化计划
  - [ ] 制定编译验证计划
  - [ ] 制定测试计划（如需要）
  - [ ] 说明回滚方案

- [ ] **等待用户确认**
  - [ ] 实施文档已提交给用户
  - [ ] 等待用户确认后才能继续

### 阶段 3：开发阶段

- [ ] **步骤 3：修改代码**
  - [ ] 按照实施文档执行修改
  - [ ] 保持代码风格一致性
  - [ ] 遵循项目编码规范
  - [ ] 添加必要的注释
  - [ ] 确保代码逻辑正确

### 阶段 4：优化阶段

- [ ] **步骤 4：优化本次修改的代码**
  - [ ] **清理无引用的类**
    - [ ] 检查是否有未使用的类
    - [ ] 删除所有无引用的类
  - [ ] **清理无引用的方法**
    - [ ] 检查是否有未使用的方法
    - [ ] 删除所有无引用的方法（注意接口方法、注解方法除外）
  - [ ] **清理无引用的变量**
    - [ ] 检查是否有未使用的变量
    - [ ] 检查是否有未使用的常量
    - [ ] 检查是否有未使用的字段
    - [ ] 删除所有无引用的变量
  - [ ] **清理无用的导入**
    - [ ] 检查是否有未使用的 import 语句
    - [ ] 删除所有无用的导入
  - [ ] **代码重构**
    - [ ] 优化代码结构
    - [ ] 提高代码可读性
    - [ ] 统一代码风格
  - [ ] **注释完善**
    - [ ] 确保关键代码有必要的注释
    - [ ] 清理过时的注释

### 阶段 5：验证阶段

- [ ] **步骤 5：编译验证**
  - [ ] 执行编译命令
  - [ ] **检查编译错误**
    - [ ] 没有编译错误
    - [ ] 所有错误已修复
  - [ ] **检查编译警告**
    - [ ] 尽量消除编译警告
    - [ ] 无法消除的警告已说明原因
  - [ ] **验证依赖关系**
    - [ ] 依赖库版本正确
    - [ ] 依赖库可访问
    - [ ] 无依赖冲突
  - [ ] **运行测试**（如适用）
    - [ ] 所有测试用例通过
  - [ ] **生成验证报告**
    - [ ] 记录编译状态
    - [ ] 记录错误和警告
    - [ ] 记录依赖检查结果

### 阶段 6：Git 控制阶段

- [ ] **步骤 6：Git 操作控制**
  - [ ] **默认不执行任何 Git 操作**
    - [ ] 没有自动提交代码
    - [ ] 没有自动创建分支
    - [ ] 没有自动推送代码
    - [ ] 没有自动合并分支
    - [ ] 没有自动打标签
  - [ ] **只有在用户明确要求时才执行**
    - [ ] 用户明确要求 Git 操作
    - [ ] 执行前已确认用户意图
    - [ ] 执行的操作符合用户要求

## 快速检查清单

### 必须执行（✅）

- ✅ 生成分析文档
- ✅ 等待用户确认分析文档
- ✅ 生成实施文档
- ✅ 等待用户确认实施文档
- ✅ 修改代码
- ✅ 清理无引用代码
- ✅ 编译验证
- ✅ 默认不执行 Git 操作

### 禁止执行（❌）

- ❌ 跳过分析文档直接修改代码
- ❌ 跳过实施文档直接修改代码
- ❌ 不清理无引用代码
- ❌ 不进行编译验证
- ❌ 自动执行 Git 操作（除非用户要求）

## 常见错误检查

- [ ] 是否跳过了分析文档？
- [ ] 是否在用户确认前就执行了修改？
- [ ] 是否清理了所有无引用代码？
- [ ] 是否进行了编译验证？
- [ ] 是否执行了不应该的 Git 操作？

## 完成确认

在完成所有步骤后，确认：

- [ ] 所有步骤已完成
- [ ] 所有检查项已通过
- [ ] 代码质量符合要求
- [ ] 用户已确认（如需要）
- [ ] 准备交付
